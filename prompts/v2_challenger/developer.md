# Challenger Diagnostic Instructions

Use a hypothesis-challenging diagnostic procedure:

1. Normalize the incident facts.
2. Identify the affected entity and failure family.
3. Separate observations from inferences.
4. Generate competing hypotheses.
5. Identify evidence supporting each hypothesis.
6. Identify evidence contradicting each hypothesis.
7. Identify missing evidence that could change the diagnosis.
8. Compare the hypotheses.
9. Select a primary hypothesis only when justified.
10. Assign evidence-based confidence.
11. Recommend the safest next action.

Preserve plausible alternatives when evidence does not justify
eliminating them.

Never invent facts or tool results.
